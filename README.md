## 📌 О проекте / Overview

**Ping Monitoring** — это современная десктопная утилита для Windows (.NET 8 / WPF), созданная специально для соревновательных игроков в **Dota 2, Counter-Strike 2, Deadlock, PUBG, Apex Legends, Rust** и другие онлайн-игры. 

Приложение объединяет в себе:
* **Сквозную сетевую телеметрию** серверов (включая приватные магистрали Valve SDR / Steam Datagram Relay, AWS, Riot Direct);
* **Легковесный внутриигровой HUD-оверлей** поверх любых игр с мониторингом пинга, потерь пакетов, FPS, CPU, GPU и памяти RAM;
* **Встроенный Спидтест сети (Speedtest)** с 60 FPS LERP-интерполяцией спидометра, кривыми Безье и поддержкой локализации (`Mbps` / `Мбит/с`);
* **Системный диспетчер задач Windows** для быстрого выявления фоновых процессов, нагружающих процессор и интернет;
* **MTR-диагностику узлов** маршрута для точного определения источника лагов (домашний роутер, провайдер или магистральный узел).

Интерфейс спроектирован по канонам дизайн-системы **Raycast Dark Canvas / Linear Dark** с поддержкой 7 цветовых тем оформления (включая футуристичную *Monochrome Cyber*), переключением языков на лету (RU / EN) и режимом нулевой нагрузки на видеокарту.

## ✨ Ключевые возможности / Features

### 1. 🌐 Сетевой мониторинг и Valve Steam Datagram Relay (SDR)
* **Пассивный перехват игровых матчей (100% VAC-безопасно):** Не внедряется в память игры и не модифицирует игровые файлы. Читает данные сетевых кластеров через открытые консольные события и сокеты.
* **Мульти-игровой трекер матчей:** Универсальный интерфейс трекинга для трех флагманов Valve на движке Source 2:
  * **Dota 2** — автоматический перехват матча, кластера и SDR-релея;
  * **Counter-Strike 2** — разбор SDR-подключений и саб-тиков через `csgo/console.log` (`-condebug`);
  * **Deadlock** — трекинг соревновательных лобби через консольные события Project 8.
* **Маршруты Ingress Relay ➔ Dedicated Server:** Отображает реальный пинг, джиттер, процент потерь пакетов и IATA-код дата-центра (`FRA`, `STO`, `WAW`, `AMS`, `IAD`, `SGP` и др.).
* **Кастомные цели пинга (+ Добавить сервер):** Возможность добавлять любые собственные IP-адреса и домены (выделенные серверы Faceit, TeamSpeak, Discord Voice, частные VPS) с сохранением в SQLite и быстрым удалением кнопкой `✕`.
* **Поддержка игр:** Dota 2, CS2, Deadlock, PUBG, Apex Legends, Rust, Overwatch 2, Valorant, Мир Танков.

### 2. 🎮 Настраиваемый игровой HUD-оверлей
* **5 пресетов интерфейса:**
  * `Classic Bar` — эргономичная компактная статус-строка.
  * `Ultra-Minimalist` — микро-виджет с ключевыми метриками (идеален для стримеров).
  * `Vertical Stack` — угловой вертикальный стек показателей.
  * `Pro Gamer (NetGraph)` — детальная телеметрия сетевого потока и тиков.
  * `Cyber HUD` — высококонтрастный киберспортивный визор с неоновым свечением.
* **Умное авто-скрытие вне игры (Auto-Detection Visibility):** Оверлей автоматически показывается только во время активной игры и скрывается при переходе на рабочий стол или браузер (включается через ПКМ -> `✓ Авто-скрытие вне игры`).
* **Индивидуальная настройка элементов:** Раздельное включение кардиограммы сети, счетчика FPS, нагрузки процессора (ЦП), видеокарты (ГП) и оперативной памяти (ОЗУ).
* **Сквозные клики (Click-Through):** При блокировке оверлей становится полностью прозрачным для курсора мыши и кликов в игре.

### 3. 🚀 Спидтест 60 FPS и Тест на Буферблоат (Bufferbloat)
* Многопоточный замер Download (входящей) и Upload (исходящей) скорости через CDN-узлы.
* **Экспресс-тест на буферблоат (Loaded Latency):** Измерение роста пинга под нагрузкой скачивания и отдачи с выставлением грейда качества сетевого буфера роутера (от **A+** до **F**).
* **In-Game Spike Alert:** Автоматический вывод бейджа `⚠ BLOAT` в оверлее при выявлении задержек, вызванных перегрузкой домашнего роутера.
* Анимированный радиальный спидометр с физикой интерполяции **60 FPS LERP**.
* Волна скорости на базе кубических кривых Безье (Catmull-Rom Spline) с динамическим акцентным градиентом.
* Таблица истории замеров с переключением единиц (`Мбит/с` для RU, `Mbps` для EN).

### 4. ⚡ Твики сети Windows и Игровой буст (Game Boost & Latency Tweaks)
* Доступны по кнопке **`⚡ Твики сети`** в главном окне:
  * **Отключение алгоритма Nagle** (`TCPNoDelay = 1`, `TcpAckFrequency = 1`) для снижения задержки пакетов в онлайн-играх.
  * **Отключение сетевого троттлинга Windows** (`NetworkThrottlingIndex`).
  * **Очистка DNS-кэша** (`ipconfig /flushdns`) в один клик.
  * **Быстрый перезапуск сетевого адаптера** для устранения залипаний Wi-Fi / Ethernet.
  * **Game Boost:** Безопасное повышение приоритета игры до High (CPU & I/O Priority, 100% VAC-Safe).

### 5. 📊 Диспетчер процессов с сетевым мониторингом в реальном времени
* Опрос сетевых сокетов Windows API (`iphlpapi.dll`) для точного измерения трафика (КБ/с и МБ/с) каждого отдельного процесса в реальном времени.
* Мгновенное выявление программ, забивающих интернет-канал во время матча.

### 6. 📋 Экспорт отчёта для техподдержки провайдера (ISP Ticket Export)
* Доступен по кнопке **`📋 Отчёт для техподдержки`**:
  * Мгновенное формирование профессионального обращения к интернет-провайдеру (для вставки в чат поддержки, личный кабинет или отправки по email).
  * Автоматически включает данные подключения (договор, адрес, телефон), внешний IP, отклик домашнего шлюза, результаты поузловой MTR-трассировки и журнал недавних сетевых инцидентов (тайм-ауты и спайки задержки).
  * **Полная двуязычная локализация (RU / EN):** В режиме EN обращение генерируется полностью на английском языке (`ISP Technical Support Ticket`) с международными формулировками и миллисекундами (`ms`).

### 7. ⚡ Режим оптимизации (Flat UI / Low-End PC)
* Кнопка **«⚡ Оптимизировать»** мгновенно отключает радиальные размытия, тяжелые тени и блумы, переводя интерфейс в ультралегковесный плоский режим с нулевой нагрузкой на GPU.

### 8. 🎨 Эргономичный дизайн шапки и единая сборка
* Селектор дисциплины (Dota 2, CS2) отделен тонким 1px hairline-разделителем и идеально сбалансирован с селектором сервера.
* Переключатель языка интерфейса (`RU | EN`) аккуратно интегрирован в выпадающее меню навигации (`[≡] 🌐`), не загромождая панель телеметрии.
* Автоматическая синхронизация скомпилированных бинарников исключает рассинхронизацию версий между разработкой и релизной папкой `publish/`.

## ⌨️ Управление и горячие клавиши / Hotkeys Guide

Все горячие клавиши являются глобальными и работают прямо во время игры.

| Горячая клавиша | Действие | Описание |
| :--- | :--- | :--- |
| **`Ctrl + Shift + O`** | Вкл / Выкл оверлей | Мгновенно показывает или скрывает HUD-оверлей |
| **`Ctrl + Shift + L`** | Режим сквозного клика | Фиксирует окно оверлея (клики проходят сквозь него в игру) |
| **`Ctrl + Shift + F`** | Счетчик FPS | Быстрое переключение отображения кадров в секунду |
| **`Ctrl + Shift + C`** | Нагрузка ЦП (CPU) | Включение / скрытие индикатора процессора |
| **`Ctrl + Shift + U`** | Нагрузка ГП (GPU) | Включение / скрытие индикатора видеокарты |
| **`Ctrl + Shift + R`** | Память ОЗУ (RAM) | Включение / скрытие счетчика оперативной памяти |

### Управление мышью:
* **Левый клик (ЛКМ) + перетаскивание:** Свободное перемещение HUD-оверлея в любую точку экрана (в разблокированном режиме).
* **Правый клик (ПКМ) по оверлею:** Открытие быстрого контекстного меню (выбор пресета, масштабирование 75%–180%, прозрачность, темы).
* **Правый клик (ПКМ) по хоткею в главном окне:** Мгновенное переназначение клавиши под ваши предпочтения.

## 🛠️ Сборка из исходников / Build from Source

### Требования:
* **Операционная система:** Windows 10 или Windows 11 (x64)
* **SDK:** [Microsoft .NET 8.0 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)
* **Сборщик инсталлятора (опционально):** [Inno Setup 6](https://jrsoftware.org/isdl.php)

### 1. Клонирование и запуск в режиме разработки:
```bash
# Клонирование репозитория
git clone https://github.com/Fog-root/PingMonitor.git
cd PingMonitor

# Запуск приложения
dotnet run
```

### 2. Сборка оптимизированного Production-релиза:
```bash
# Сборка Release
dotnet build -c Release

# Публикация файлов приложения
dotnet publish -c Release -o publish
```

### 3. Компиляция установочного пакета (.exe):
Для генерации полноценного инсталлятора с автоматической проверкой и докачкой .NET 8 Desktop Runtime:
```powershell
& "ISCC.exe" installer.iss
```
*Собранный установщик:* `installer_output/PingMonitoring_Setup.exe`.

### 4. Сборка портативной версии (Single-File Portable):
Для генерации автономного `.exe` без зависимостей и установки:
```powershell
dotnet publish -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true -o publish_portable
```
*Собранный портативный файл:* `installer_output/PingMonitoring_Portable.exe`.

## 🛡️ Безопасность и VAC / Privacy & Anti-Cheat

* **VAC & EAC Безопасность:** Приложение **не внедряет сторонние DLL** в адресное пространство игр и **не перехватывает память процессов**. Мониторинг полностью легитимен и безопасен для аккаунтов Steam, Epic Games и Riot.
* **Приватность:** Все измерения хранятся локально в директории `%APPDATA%\DotaPingMonitor`. Приложение не отправляет пользовательские данные на сторонние серверы и не содержит телеметрии отслеживания.
